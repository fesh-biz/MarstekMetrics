# Marstek Metrics

Программа для мониторинга, сбора телеметрии и анализа состояния зарядных станций **Marstek Venus** через локальный Open API (UDP, в одной сети Wi‑Fi со станцией).

Статус: проектирование.

- Справочник по протоколу: [docs/open-api.md](docs/open-api.md)
- Язык: Python

## Подготовка станции

1. Привяжите станцию в приложении Marstek и подключите её к Wi‑Fi.
2. Включите в приложении **Open API** и запомните UDP-порт (по умолчанию `30000`).
3. Закрепите за станцией статический IP в роутере.
