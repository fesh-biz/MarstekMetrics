# Marstek Metrics

Десктопна програма для Windows, яка стежить за станцією **Marstek Venus E 3.0** через локальний Open API. Працює по UDP у тій самій мережі Wi‑Fi, без хмари.

- **Зараз** — споживання будинку, імпорт/експорт мережі, що робить станція, заряд батареї, режим, CT-лічильник, Wi‑Fi; графік потужностей за 1 год / 6 год / 24 год / 7 днів.
- **Споживання** — скільки спожив будинок сьогодні, учора, за 7 і 30 днів; графік і таблиця за днями: з мережі, у мережу, скільки віддала станція і скільки взяла на заряджання.
- **Помилки** — активні проблеми та журнал: станція не відповідає, CT відключено, слабкий Wi‑Fi, низький заряд, перегрів, заборона заряджання/розряджання, скидання лічильників, зміна режиму та прошивки.

Історія зберігається локально в SQLite, типово рік.

Протокол станції: [docs/open-api.md](docs/open-api.md).

## Підготовка станції

1. Станцію прив'язано в застосунку Marstek і підключено до Wi‑Fi.
2. У застосунку ввімкнено **Open API**, типовий порт `30000`.
3. У роутері за станцією закріплено постійну IP-адресу.
4. Для розрахунку споживання будинку потрібен підключений CT-лічильник (CT002/CT003).

## Встановлення (Windows)

**[Завантажити MarstekMetrics.exe](https://github.com/fesh-biz/MarstekMetrics/releases/download/latest/MarstekMetrics.exe)** і запустити. Python не потрібен.

- Файл не підписаний, тому Windows SmartScreen може показати «Windows захистив ваш ПК» — натисніть «Докладніше» → «Виконати в будь-якому разі».
- Перший запуск триває кілька секунд: програма розпаковується.
- Під час першого запуску відкриються налаштування: натисніть «Знайти в мережі» або впишіть IP станції.
- Якщо Windows запитає про брандмауер — дозвольте доступ у **приватних мережах**, інакше відповіді станції не дійдуть.

Нова збірка з'являється автоматично після кожного оновлення коду.

Запускайте безпосередньо у Windows, не у WSL2: частина прошивок відповідає на порт 30000, а NAT WSL2 такі відповіді не пропускає.

### Встановлення з вихідного коду (для розробки)

Потрібен Python 3.11+ з [python.org](https://www.python.org/downloads/).

```powershell
git clone https://github.com/fesh-biz/MarstekMetrics.git
cd MarstekMetrics
py -m venv .venv
.venv\Scripts\python -m pip install -e .[dev]
.venv\Scripts\marstek-metrics
```

Команди звертаються до `.venv\Scripts\` напряму, тож активація середовища (і зміна політики виконання PowerShell) не потрібна.

### Перевірка зв'язку з консолі

```bat
marstek-cli discover
marstek-cli status 192.168.1.50
marstek-cli raw 192.168.1.50 all
```

`raw` друкує відповіді станції як є — їх зручно надіслати, якщо щось показується неправильно.

### Без станції

Емулятор Venus E 3.0 (прошивка 150) з реалістичним навантаженням і втратою 10% пакетів:

```bat
python -m marstek_metrics.mock
```

У налаштуваннях програми вкажіть IP `127.0.0.1`.

### Власне збирання .exe

```powershell
.venv\Scripts\pyinstaller --noconfirm --clean --windowed --onefile --name MarstekMetrics run_gui.py
```

Вийде `dist\MarstekMetrics.exe`. Те саме робить GitHub Actions (`.github/workflows/build.yml`) після кожного пушу в `main`: проганяє тести на Windows і оновлює реліз `latest`.

## Як рахується споживання

| Величина | Звідки |
|----------|--------|
| Мережа | `EM.GetStatus → total_power`: + беремо з мережі, − віддаємо |
| Станція | `ES.GetStatus → ongrid_power`: + віддає в будинок, − заряджається |
| Off-grid | `ES.GetStatus → offgrid_power` |
| **Споживання будинку** | мережа + станція + off-grid |
| Батарея | `bat_power`, а якщо його немає (Venus E 3.0) — за балансом потужностей |

Енергія за день — інтеграл потужності між вимірами. Розриви понад 5 хвилин (програму вимкнено, станція не відповідала) не враховуються, тому в таблиці є колонка «Даних за день». Віддача і заряджання станції беруться з її власних лічильників, якщо вони є.

Знаки потужностей узято з документації та досвіду спільноти. Якщо на вашій станції споживання будинку виглядає неправдоподібно, надішліть вивід `marstek-cli raw IP all`.

## Опитування

Раз на 30 с програма послідовно запитує `ES.GetStatus`, `EM.GetStatus` і `ES.GetMode`, раз на 10 циклів — Wi‑Fi. На кожен запит — очікування 10 с і 2 повтори. Частіше ніж раз на 30 с опитувати не варто: станція може стати нестабільною.

Дані BMS (`Bat.GetStatus`: температура, заборони заряджання/розряджання) типово вимкнено — на деяких прошивках цей запит перезавантажує станцію. Вмикаються в налаштуваннях.

## Де лежать дані

`%LOCALAPPDATA%\MarstekMetrics\`: `config.json`, `metrics.db`, `marstek-metrics.log`.

## Розробка

```bat
pip install -e .[dev]
pytest
```

Структура:

```
marstek_metrics/
  protocol.py   UDP-клієнт: тайм-аути, повтори, широкомовний пошук
  device.py     методи Open API
  models.py     нормалізація відповідей за моделлю та прошивкою
  poller.py     фонове опитування
  metrics.py    споживання за днями
  alerts.py     правила помилок і попереджень
  storage.py    SQLite
  mock.py       емулятор станції
  cli.py        консольна утиліта
  gui/          вікно на PySide6 + pyqtgraph
```
